# Антипаттерн

**Active Record** — паттерн доступа к данным, при котором объект сам содержит методы для своего чтения, сохранения и удаления из хранилища.

```cs
var user = User.Find(id);

user.Name = "Alex";
user.Save();

user.Delete();
```

То есть Entity одновременно содержит:
- данные
+ часть бизнес-логики
+ persistence logic

Недостатки Active Record:

- нарушает **Persistence Ignorance** — доменная модель знает, как она хранится
- нарушает **SRP** — Entity отвечает и за бизнес-поведение, и за persistence
- противоречит **DIP** — Domain начинает зависеть от инфраструктурных деталей
- плохо сочетается с **Clean / Onion / Hexagonal Architecture**
- усложняет построение **Rich Domain Model**, потому что persistence-логика смешивается с доменной
- сильнее связывает код с конкретным ORM / БД
- усложняет тестирование доменной логики в изоляции
