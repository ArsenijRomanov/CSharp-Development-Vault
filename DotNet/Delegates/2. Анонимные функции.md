# 1. Определение

Анонимная функция — функция без имени, которая объявляется непосредственно в выражении и преобразуется в совместимый тип делегата.

В C# есть две формы:
- анонимный метод
- лямбда-выражение

---
# 2. Анонимный метод

Синтаксис:

~~~csharp
delegate (параметры)
{
    тело
}
~~~

Пример:

~~~csharp
Operation add = delegate (int a, int b)
{
    return a + b;
};
~~~

Ключевое слово `delegate` здесь не объявляет новый тип делегата, а создаёт анонимную функцию.

У анонимного метода типы параметров указываются явно.

Список параметров можно полностью опустить, если они не используются:

~~~csharp
MessageHandler handler = delegate
{
    Console.WriteLine("Message received");
};
~~~

---
# 3. Лямбда-выражение

Лямбда — более компактная форма анонимной функции.

## Лямбда-выражение

~~~csharp
Operation add = (a, b) => a + b;
~~~

Правая часть является одним выражением, результат которого автоматически возвращается.

## Блочная лямбда

~~~csharp
Operation add = (a, b) =>
{
    return a + b;
};
~~~

Для одного параметра скобки можно опустить:

~~~csharp
Transformer square = value => value * value;
~~~

---
# 4. Целевой тип

Анонимная функция обычно не имеет самостоятельного типа.

Её сигнатура определяется типом делегата, в который она преобразуется.

~~~csharp
delegate int Operation(int a, int b);

Operation add = (a, b) => a + b;
~~~

Анонимная функция должна быть совместима с делегатом по:
- количеству параметров
- типам параметров
- модификаторам `ref`, `in`, `out`
- типу возвращаемого значения

В лямбде типы параметров обычно выводятся из целевого делегата:

~~~csharp
Operation add = (a, b) => a + b;
~~~

Но их можно указать явно:

~~~csharp
Operation add = (int a, int b) => a + b;
~~~

# 5. Захват внешних переменных

Анонимная функция может обращаться к локальным переменным, параметрам и `this` из внешней области видимости.

~~~csharp
int factor = 2;

Transformer multiply = value => value * factor;
~~~

Захватывается сама переменная, а не копия её значения.

~~~csharp
factor = 10;

multiply(3); // 30
~~~

Компилятор обычно переносит захваченные переменные в поля скрытого объекта замыкания.

Концептуально:

~~~text
локальная переменная
        ↓
поле объекта замыкания
        ↓
внешний код и анонимная функция работают с одним полем
~~~

Несколько анонимных функций могут использовать одну и ту же захваченную переменную.

Захваченная переменная продолжает существовать, пока достижим использующий её делегат.

---
# 6. Захват `this`

Если анонимная функция обращается к полям или методам текущего объекта, она захватывает `this`.

~~~csharp
return () => _value++;
~~~

В таком случае делегат удерживает ссылку на весь объект, а не только на конкретное поле.

---
# 7. Статические анонимные функции

Модификатор `static` запрещает захват внешнего состояния.

~~~csharp
Transformer square = static value => value * value;
~~~

Статическая анонимная функция не может использовать:

- локальные переменные внешнего метода
- параметры внешнего метода
- `this`
- `base`

Это позволяет явно гарантировать отсутствие замыкания.

---
# 8. Анонимные функции в циклах

В цикле `for` все функции могут захватить одну общую переменную цикла:

~~~csharp
for (int i = 0; i < 3; i++)
    actions.Add(() => Console.WriteLine(i));
~~~

После завершения цикла все функции увидят итоговое значение `i`.

Для отдельного значения на каждой итерации создаётся новая локальная переменная:

~~~csharp
for (int i = 0; i < 3; i++)
{
    int copy = i;
    actions.Add(() => Console.WriteLine(copy));
}
~~~

---
# 9. Асинхронные анонимные функции

Анонимная функция может иметь модификатор `async`.

~~~csharp
AsyncOperation operation = async () =>
{
    await DoWorkAsync();
    return 42;
};
~~~

Внутри неё можно использовать `await`.

---
# 10. Внутренняя реализация

Компилятор преобразует анонимную функцию в скрытый метод.

При наличии захвата он обычно дополнительно создаёт объект замыкания.

Конкретная реализация не гарантируется.

Компилятор может:

- создать статический или экземплярный скрытый метод
- создать один или несколько объектов замыкания
- объединить несколько захваченных переменных
- кэшировать делегат, если захвата нет

Гарантируется поведение функции, но не конкретное устройство сгенерированного кода.
