
`Action`, `Func` и `Predicate` — стандартные типы делегатов из пространства имён `System`

---
# 1. Action

Представляет метод без возвращаемого значения

~~~csharp
Action action
Action<int> action
Action<int, string> action
~~~

Все типы в угловых скобках задают параметры метода

---
# 2. Func

Представляет метод с возвращаемым значением

~~~csharp
Func<int> function
Func<string, int> function
Func<int, string, bool> function
~~~

Последний тип задаёт возвращаемое значение, остальные — параметры метода

---
# 3. Predicate

Представляет метод, который принимает один параметр типа `T` и возвращает `bool`

~~~csharp
Predicate<int> predicate
~~~

По сигнатуре соответствует `Func<T, bool>`, но является отдельным типом делегата

---
# 4. Вариантность

Входные параметры стандартных делегатов контрвариантны и объявлены через `in`.
Возвращаемый тип `Func` ковариантен и объявлен через `out`.

```csharp
Action<in T>
Predicate<in T>
Func<in T, out TResult>
```

Это разрешает преобразования между делегатами с совместимыми ссылочными типами:

```csharp
Action<Animal> handleAnimal = HandleAnimal;
Action<Cat> handleCat = handleAnimal;

Func<Cat> createCat = CreateCat;
Func<Animal> createAnimal = createCat;
```

Вариантность применяется только к ссылочным типам.
