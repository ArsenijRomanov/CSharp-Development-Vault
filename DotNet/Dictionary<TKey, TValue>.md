

- Использует **хеш-таблицу с чейнингом**.
- Внутри два массива:
    - `buckets[]` — хранит индекс начала цепочки;
    - `entries[]` — хранит все элементы.

```cs
struct Entry
{
    int next;
    TKey key;
    TValue value;
}
```

Поиск:

1. Вычисляется хеш ключа.
2. По хешу определяется bucket.
3. `buckets[bucket]` даёт индекс первой записи.
4. По полю `next` обходится цепочка коллизий.
5. Ключи сравниваются через `EqualityComparer<TKey>`.

Схема:

```
buckets[2] → entries[7] → entries[4] → entries[1]
```

Все записи физически лежат в одном `entries[]`, а `next` создаёт логические цепочки.
