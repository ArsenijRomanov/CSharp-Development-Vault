Паттерн Прототип (Prototype) позволяет создавать объекты на основе уже ранее созданных объектов-прототипов. То есть по сути данный паттерн предлагает технику клонирования объектов.

Паттерн применяют, когда объект сложно или дорого создавать с нуля либо когда нужно создавать много похожих объектов

## Структура

- `Prototype` объявляет метод `Clone()`
- конкретные прототипы реализуют копирование самих себя
- клиент работает через общий тип и не знает конкретный класс объекта

```cs
public interface IPrototype<T>
{
    T Clone();
}
```

```cs
public sealed class Enemy : IPrototype<Enemy>
{
    public string Name { get; set; } = string.Empty;
    public int Health { get; set; }

    public Enemy Clone()
    {
        return new Enemy
        {
            Name = Name,
            Health = Health
        };
    }
}
```

## Поверхностная копия

**Shallow copy** создаёт новый внешний объект, но вложенные ссылочные объекты остаются общими

```cs
public Enemy Clone()
{
    return (Enemy)MemberwiseClone();
}
```

Изменение общего вложенного объекта будет видно и через оригинал, и через копию

## Глубокая копия

**Deep copy** копирует также вложенные изменяемые объекты

```cs
public Enemy Clone()
{
    var copy = (Enemy)MemberwiseClone();

    copy.Position = new Position
    {
        X = Position.X,
        Y = Position.Y
    };

    copy.Skills = new List<string>(Skills);

    return copy;
}
```

Глубина копирования определяется бизнес-смыслом: не каждый вложенный объект обязательно нужно дублировать

## Реализация в C\#

Обычно используют:

- типизированный метод `Clone()`
- копирующий конструктор
- `MemberwiseClone()` для поверхностной копии
- `record` и выражение `with`

```cs
var copy = original with { Health = 200 };
```
