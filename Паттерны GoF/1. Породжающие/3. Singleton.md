Одиночка (Singleton) - порождающий паттерн, который гарантирует, что для определенного класса будет создан только один объект, а также предоставит к этому объекту точку доступа.

Классическая реализация:

```cs
public sealed class Singleton
{
    public static Singleton Instance { get; }
	
    static Singleton()
    {
        Instance = new Singleton();
    }
	
    private Singleton()
    {
    }
}
```

Ленивая инициализация:

```cs
public sealed class Singleton
{
    private static readonly Lazy<Singleton> _instance =
        new(() => new Singleton());
	
    public static Singleton Instance => _instance.Value;
	
    private Singleton()
    {
    }
}
```


Классический Singleton совмещает в одном классе бизнес-логику, управление временем жизни и глобальную точку доступа к экземпляру, поэтому делегируем это DI-контейнеру:

```cs
builder.Services.AddSingleton<IUserCache, UserCache>();
```
