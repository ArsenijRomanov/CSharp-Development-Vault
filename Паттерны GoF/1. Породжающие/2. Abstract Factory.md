Паттерн "Абстрактная фабрика" (Abstract Factory) предоставляет интерфейс для создания семейств взаимосвязанных объектов с определенными интерфейсами без указания конкретных типов данных объектов.

### Когда использовать абстрактную фабрику

- Когда система не должна зависеть от способа создания и компоновки новых объектов
    
- Когда создаваемые объекты должны использоваться вместе и являются взаимосвязанными

## Проблема

Допустим, приложение поддерживает разные стили интерфейса:

- Windows
- macOS

Для каждого стиля нужны согласованные компоненты:

- кнопка
- чекбокс

Без абстрактной фабрики клиенту придётся самостоятельно выбирать конкретные классы:

```cs
IButton button;
ICheckbox checkbox;

if (platform == "Windows")
{
    button = new WindowsButton();
    checkbox = new WindowsCheckbox();
}
else
{
    button = new MacButton();
    checkbox = new MacCheckbox();
}
```

Такой код:

- зависит от конкретных классов
- содержит условную логику создания

## Структура паттерна

Участники:

- **AbstractFactory** — интерфейс создания семейства продуктов
- **ConcreteFactory** — создаёт конкретное семейство
- **AbstractProduct** — общий интерфейс продукта
- **ConcreteProduct** — конкретная реализация продукта
- **Client** — работает только с абстракциями

## Реализация

### Абстрактные продукты

```cs
public interface IButton
{
    void Render();
}

public interface ICheckbox
{
    void Render();
}
```

### Продукты Windows

```cs
public sealed class WindowsButton : IButton
{
    public void Render()
    {
        Console.WriteLine("Windows button");
    }
}

public sealed class WindowsCheckbox : ICheckbox
{
    public void Render()
    {
        Console.WriteLine("Windows checkbox");
    }
}
```

### Продукты macOS

```cs
public sealed class MacButton : IButton
{
    public void Render()
    {
        Console.WriteLine("macOS button");
    }
}

public sealed class MacCheckbox : ICheckbox
{
    public void Render()
    {
        Console.WriteLine("macOS checkbox");
    }
}
```

### Абстрактная фабрика

```cs
public interface IUiFactory
{
    IButton CreateButton();
    ICheckbox CreateCheckbox();
}
```

### Конкретные фабрики

```cs
public sealed class WindowsUiFactory : IUiFactory
{
    public IButton CreateButton()
    {
        return new WindowsButton();
    }

    public ICheckbox CreateCheckbox()
    {
        return new WindowsCheckbox();
    }
}
```

```cs
public sealed class MacUiFactory : IUiFactory
{
    public IButton CreateButton()
    {
        return new MacButton();
    }

    public ICheckbox CreateCheckbox()
    {
        return new MacCheckbox();
    }
}
```

### Клиент

```cs
public sealed class Application
{
    private readonly IButton _button;
    private readonly ICheckbox _checkbox;

    public Application(IUiFactory factory)
    {
        _button = factory.CreateButton();
        _checkbox = factory.CreateCheckbox();
    }

    public void Render()
    {
        _button.Render();
        _checkbox.Render();
    }
}
```
