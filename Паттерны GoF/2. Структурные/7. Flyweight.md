**Приспособленец** — структурный паттерн, который уменьшает потребление памяти за счёт совместного использования общих объектов вместо создания большого количества одинаковых экземпляров

# Когда применять

Flyweight подходит, когда:

- создаётся очень большое количество объектов
- объекты потребляют значительный объём памяти
- большая часть их состояния повторяется
- повторяющееся состояние можно сделать неизменяемым
- уникальное состояние можно хранить или передавать отдельно
- совместное использование объектов не меняет их семантику

## Участники паттерна

- **Flyweight** — общий контракт приспособленцев
- **ConcreteFlyweight** — разделяемый объект, хранящий внутреннее состояние
- **UnsharedConcreteFlyweight** — объект того же контракта, который не разделяется
- **FlyweightFactory** — создаёт, хранит и повторно выдаёт `ConcreteFlyweight`
- **Client** — получает приспособленцев из фабрики и передаёт им внешнее состояние

## Внутреннее и внешнее состояние

### Внутреннее состояние — intrinsic state

Хранится внутри `ConcreteFlyweight` и разделяется между клиентами

Обычно оно:

- одинаково для множества объектов
- неизменяемо
- не зависит от конкретного использования

### Внешнее состояние — extrinsic state

Не хранится в разделяемом объекте

Клиент передаёт его при выполнении операции

# Формальное представление на C#

## Flyweight

Объявляет операцию, принимающую внешнее состояние:

```cs
public abstract class Flyweight
{
    public abstract void Operation(int extrinsicState);
}
```

## ConcreteFlyweight

Разделяемый приспособленец

Хранит внутреннее состояние:

```cs
public sealed class ConcreteFlyweight : Flyweight
{
    private readonly int _intrinsicState;

    public ConcreteFlyweight(int intrinsicState)
    {
        _intrinsicState = intrinsicState;
    }

    public override void Operation(int extrinsicState)
    {
        Console.WriteLine(
            $"Intrinsic state: {_intrinsicState}, " +
            $"extrinsic state: {extrinsicState}");
    }
}
```

## UnsharedConcreteFlyweight

Реализует тот же контракт, но не предназначен для совместного использования:

```cs
public sealed class UnsharedConcreteFlyweight : Flyweight
{
    private readonly int _allState;

    public UnsharedConcreteFlyweight(int allState)
    {
        _allState = allState;
    }

    public override void Operation(int extrinsicState)
    {
        Console.WriteLine(
            $"Unshared state: {_allState}, " +
            $"extrinsic state: {extrinsicState}");
    }
}
```

Такой объект создаётся отдельно для конкретного клиента и не хранится в фабрике

## FlyweightFactory

Фабрика хранит разделяемые объекты и возвращает существующий экземпляр по ключу:

```cs
public sealed class FlyweightFactory
{
    private readonly Dictionary<string, Flyweight> _flyweights = [];

    public Flyweight GetFlyweight(string key)
    {
        if (_flyweights.TryGetValue(
                key,
                out Flyweight? flyweight))
        {
            return flyweight;
        }

        flyweight = new ConcreteFlyweight(
            intrinsicState: key.GetHashCode());

        _flyweights[key] = flyweight;

        return flyweight;
    }
}
```

При повторном обращении с тем же ключом новый объект не создаётся:

```cs
Flyweight first = factory.GetFlyweight("A");
Flyweight second = factory.GetFlyweight("A");

Console.WriteLine(
    ReferenceEquals(first, second)); // true
```

## Client

```cs
public static class Client
{
    public static void Main()
    {
        var factory = new FlyweightFactory();

        Flyweight first =
            factory.GetFlyweight("A");

        Flyweight second =
            factory.GetFlyweight("A");

        Flyweight third =
            factory.GetFlyweight("B");

        first.Operation(extrinsicState: 10);
        second.Operation(extrinsicState: 20);
        third.Operation(extrinsicState: 30);

        Flyweight unshared =
            new UnsharedConcreteFlyweight(
                allState: 100);

        unshared.Operation(extrinsicState: 40);
    }
}
```

# Примеры

## Интернирование строк

Одинаковые строковые литералы могут ссылаться на один объект:

```cs
string first = "hello";
string second = "hello";

Console.WriteLine(ReferenceEquals(first, second)); // true
```

CLR использует таблицу интернированных строк и переиспользует одинаковые экземпляры

```cs
"hello" ──┐
          ├──► один объект string
"hello" ──┘
```

## Кэширование `Int?` в Kotlin/JVM

В Kotlin/JVM `Int?` - ссылочный immutable-объект

Для небольших чисел JVM переиспользует заранее созданные объекты `Integer`, гарантированно в диапазоне `-128..127`

```kotlin
val first: Int? = 100
val second: Int? = 100

println(first === second) // true
```

Обе переменные ссылаются на один кэшированный объект:

```kotlin
first  ──┐
         ├──► Integer(100)
second ──┘
```
