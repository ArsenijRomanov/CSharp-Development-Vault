
**Компоновщик** — структурный паттерн, который объединяет отдельные объекты и их группы в древовидную структуру и позволяет клиенту одинаково работать как с одним объектом, так и с целой группой

![[Pasted image 20260727144235.png]]

## Участники паттерна

- **Component** — общий контракт для одиночных объектов и групп
- **Leaf** — конечный объект, который не содержит дочерних элементов
- **Composite** — составной объект, который хранит другие компоненты
- **Client** — работает со всеми элементами через общий контракт

Leaf и Composite имеют общий контракт.

# Пример: файлы и папки

Общий компонент:

```cs
public interface IFileSystemItem
{
    string Name { get; }
    long GetSize();
}
```

## Leaf

Файл является конечным элементом дерева:

```cs
public sealed class FileItem : IFileSystemItem
{
    public FileItem(string name, long size)
    {
        Name = name;
        Size = size;
    }

    public string Name { get; }
    public long Size { get; }

    public long GetSize() => Size;
}
```

## Composite

Папка содержит файлы и другие папки:

```cs
public sealed class DirectoryItem : IFileSystemItem
{
    private readonly List<IFileSystemItem> _children = [];

    public DirectoryItem(string name)
    {
        Name = name;
    }

    public string Name { get; }

    public void Add(IFileSystemItem item)
    {
        _children.Add(item);
    }

    public void Remove(IFileSystemItem item)
    {
        _children.Remove(item);
    }

    public long GetSize()
    {
        return _children.Sum(child => child.GetSize());
    }
}
```

Использование:

```cs
var documents = new DirectoryItem("Documents");

documents.Add(new FileItem("resume.pdf", 1_000));
documents.Add(new FileItem("notes.txt", 500));

var images = new DirectoryItem("Images");

images.Add(new FileItem("photo.jpg", 3_000));
images.Add(new FileItem("logo.png", 1_500));

documents.Add(images);

long size = documents.GetSize(); // 6000
```

Клиенту не нужно проверять, перед ним файл или папка:

```cs
static void PrintSize(IFileSystemItem item)
{
    Console.WriteLine($"{item.Name}: {item.GetSize()}");
}
```

Метод одинаково работает с обоими вариантами:

```cs
PrintSize(new FileItem("test.txt", 100));
PrintSize(documents);
```

# Где применяется

## Иерархические категории

```
Каталог
├── Электроника
│   ├── Телефоны
│   └── Ноутбуки
└── Одежда
```

Категория может содержать товары и другие категории. Общие операции:

- подсчёт товаров
- вычисление общей стоимости
- поиск
- построение дерева каталога

## Организационная структура

```
Компания
├── Департамент
│   ├── Команда
│   │   ├── Сотрудник
│   │   └── Сотрудник
```

Можно одинаково рассчитывать численность, бюджет или фонд оплаты труда для сотрудника, команды или целого подразделения

## Меню и UI

```
Menu
├── MenuItem
├── Submenu
│   ├── MenuItem
│   └── MenuItem
```

Одиночный элемент и группа могут иметь общие операции отображения, проверки доступности и выполнения команд

## Выражения и правила

```
AND
├── AgeGreaterThan
└── OR
    ├── HasRole
    └── IsOwner
```

Так строятся:

- фильтры
- спецификации
- правила валидации
- политики доступа
- поисковые выражения
- AST и expression trees
