**Шаблонный метод** — поведенческий паттерн, который определяет общий каркас алгоритма в базовом классе, оставляя отдельные шаги для переопределения подклассами

Последовательность шагов фиксируется базовым классом, а подклассы изменяют только отдельные части алгоритма

## Проблема

Несколько классов могут выполнять почти одинаковый алгоритм, отличаясь только отдельными шагами

Без паттерна общий порядок действий дублируется:

```cs
public void Execute()
{
    Step1();
    SpecificStep();
    Step3();
}
```

`Template Method` позволяет вынести общий каркас в базовый класс и предоставить подклассам точки расширения

## Когда применять

Паттерн подходит, когда:

- несколько алгоритмов имеют одинаковую последовательность шагов
- изменяются только отдельные этапы
- порядок выполнения должен контролироваться базовым классом
- необходимо устранить дублирование общего алгоритма
- подклассам нужно разрешить расширять поведение только в определённых местах

## Участники паттерна

- **AbstractClass** — определяет шаблонный метод и общий порядок выполнения алгоритма
- **ConcreteClass** — реализует или переопределяет отдельные шаги алгоритма

---

## Формальное представление на C\#

### 1. AbstractClass

Содержит шаблонный метод, который фиксирует последовательность шагов

```cs
public abstract class AbstractClass
{
    public void TemplateMethod()
    {
        CommonStep();
        RequiredStep();
        Hook();
        FinalStep();
    }

    private void CommonStep()
    {
        Console.WriteLine("Общий первый шаг");
    }

    protected abstract void RequiredStep();

    protected virtual void Hook()
    {
    }

    private void FinalStep()
    {
        Console.WriteLine("Общий завершающий шаг");
    }
}
```

`TemplateMethod()` обычно не переопределяется подклассами, потому что именно он задаёт структуру алгоритма

Методы внутри шаблона могут быть:

- обычными — имеют фиксированную реализацию
- абстрактными — обязательно реализуются подклассами
- виртуальными — имеют реализацию по умолчанию, но могут быть переопределены

### 2. ConcreteClass

Реализует изменяемые шаги алгоритма

```cs
public sealed class ConcreteClass : AbstractClass
{
    protected override void RequiredStep()
    {
        Console.WriteLine(
            "ConcreteClass выполняет обязательный шаг");
    }

    protected override void Hook()
    {
        Console.WriteLine(
            "ConcreteClass выполняет дополнительный шаг");
    }
}
```

### Использование

```cs
AbstractClass algorithm = new ConcreteClass();

algorithm.TemplateMethod();
```

## Hook

**Hook** — необязательный шаг алгоритма с пустой реализацией или поведением по умолчанию

```cs
protected virtual void Hook()
{
}
```
