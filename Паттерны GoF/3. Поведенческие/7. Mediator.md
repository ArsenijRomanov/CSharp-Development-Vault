**Mediator** — поведенческий паттерн, который выносит взаимодействие между группой объектов в отдельный объект-посредник

Объекты больше не обращаются друг к другу напрямую:


без Mediator:

- `ComponentA` $\rightarrow$ `ComponentB`
- `ComponentA` $\rightarrow$ `ComponentC`
- `ComponentB` $\rightarrow$ `ComponentC`
- `ComponentC` $\rightarrow$ `ComponentA`


Вместо этого они взаимодействуют через посредника:

```
ComponentA ─┐
ComponentB ─┼→ Mediator
ComponentC ─┘
```

Посредник знает, как компоненты должны взаимодействовать, а сами компоненты знают только о посреднике

---

## Проблема

Допустим, несколько компонентов напрямую вызывают друг друга:

```cs
public sealed class ComponentA
{
    private readonly ComponentB _componentB;
    private readonly ComponentC _componentC;

    public void Execute()
    {
        _componentB.DoSomething();
        _componentC.DoSomethingElse();
    }
}
```

При увеличении количества компонентов возникает плотная сеть зависимостей:

- компоненты знают друг о друге
- изменение одного компонента затрагивает остальные
- координационная логика распределяется между классами
- компоненты сложно использовать и тестировать отдельно

Mediator переносит правила взаимодействия в один объект

---

## Когда применять

Паттерн подходит, когда:

- несколько объектов активно взаимодействуют друг с другом
- между компонентами образуется большое количество прямых зависимостей
- взаимодействие представляет отдельный сценарий или процесс
- компоненты должны быть переиспользуемыми независимо друг от друга
- координационную логику нужно сосредоточить в одном месте

---

# Участники паттерна

- **Mediator** — объявляет контракт взаимодействия между компонентами
- **ConcreteMediator** — координирует работу конкретных компонентов
- **Colleague** — базовый тип компонента, связанного с посредником
- **ConcreteColleague** — конкретный компонент, который передаёт события посреднику и получает от него команды

---

# Формальное представление

## Mediator

```cs
public interface IMediator
{
    void Notify(
        Component sender,
        string eventName);
}
```

Компоненты уведомляют посредника о произошедшем событии, но не знают, кто должен на него отреагировать


## Colleague

```cs
public abstract class Component
{
    protected IMediator Mediator { get; }

    protected Component(IMediator mediator)
    {
        Mediator = mediator;
    }
}
```


## ConcreteColleague

```cs
public sealed class ComponentA : Component
{
    public ComponentA(IMediator mediator)
        : base(mediator)
    {
    }

    public void Execute()
    {
        Console.WriteLine("ComponentA выполнил операцию");

        Mediator.Notify(this, "A completed");
    }

    public void AdditionalOperation()
    {
        Console.WriteLine(
            "ComponentA выполнил дополнительную операцию");
    }
}
```

```cs
public sealed class ComponentB : Component
{
    public ComponentB(IMediator mediator)
        : base(mediator)
    {
    }

    public void Execute()
    {
        Console.WriteLine("ComponentB выполнил операцию");

        Mediator.Notify(this, "B completed");
    }

    public void AdditionalOperation()
    {
        Console.WriteLine(
            "ComponentB выполнил дополнительную операцию");
    }
}
```

## ConcreteMediator

Посредник содержит правила взаимодействия компонентов:

```cs
public sealed class ConcreteMediator : IMediator
{
    public ComponentA ComponentA { get; set; } = null!;
    public ComponentB ComponentB { get; set; } = null!;

    public void Notify(
        Component sender,
        string eventName)
    {
        if (eventName == "A completed")
        {
            ComponentB.AdditionalOperation();
        }

        if (eventName == "B completed")
        {
            ComponentA.AdditionalOperation();
        }
    }
}
```

Компоненты не вызывают друг друга напрямую

---

## Сборка объектов

```cs
var mediator = new ConcreteMediator();

var componentA = new ComponentA(mediator);
var componentB = new ComponentB(mediator);

mediator.ComponentA = componentA;
mediator.ComponentB = componentB;

componentA.Execute();
```
